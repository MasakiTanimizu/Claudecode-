# STEP7: UI設計

雀魂の華やかさと天鳳の軽さの中間。卓は緑のフェルトと象牙色の牌の質感を残しつつ、演出は必要な瞬間（ドラ表示・リーチ・和了）だけに絞る。

## デザイントークン

**カラー**: Felt（卓）#0B3C2E / Tile（牌）#F3ECD8 / Gold（ドラ・祝儀）#C6A24C / Danger（リーチ棒）#8B2E2E / Chrome（HUD）#12151A

**タイポグラフィ**: CJK可変フォントの埋め込みは困難なため、システムのJP系フォントスタックを使い、太さ・字間・配色で高級感を出す（和了・リーチ等のバナーは太字＋字間を広げる）。点数・残り枚数は`tabular-nums`で桁を揃える。

**レイアウト方針**: 卓を画面いっぱいに使い、自分の手牌は常に画面下部に固定。3人打ちで対面席が無いため、相手2人の情報は卓上部の左右にコンパクトに配置し、卓中央にドラ表示・残り枚数・局情報を置く。操作ボタンは手牌のすぐ上の一列に集約する。

## 対局画面の要点

- 抜いた北・華牌は各プレイヤーの情報のすぐ下に**常に上段=北、下段=華の2段固定**で表示し、抜いた順序に関わらず一目で区別できるようにする（該当牌が無い段は「―」）
- 自摸った牌は少し間隔を空けて右端に置き、今引いた牌が常に分かるようにする

## 画面構成

ホームの主要な導線は**「対戦」と「友人戦」の2つのみ**。CPU戦とオンライン対戦を別ボタンで選ばせない。

| 画面 | 内容 |
|---|---|
| ホーム/ロビー | 「対戦」「友人戦」の2導線＋戦績サマリー、フレンド・設定・リプレイ・オフライン練習への導線 |
| マッチング待機 | 「対戦」タップ直後、最大7秒のカウントダウン |
| オフライン練習セットアップ | CPU難易度を手動選択。ネットワーク不要、戦績には反映されない |
| 友人戦ルーム | ルーム作成／入室／ルーム内ロビー |
| 対局画面 | 「対戦」・オフライン練習・友人戦で共通のコンポーネント |
| 結果画面 | 局結果／半荘結果（順位・ウマ・素点ボーナス・祝儀内訳） |
| ルール設定 | STEP5のトグルをカテゴリ分けして表示（下記） |
| プロフィール/戦績 | 難易度帯別の祝儀収支、平均着順、役満達成履歴（段位バッジは廃止） |
| フレンド / 対局履歴・リプレイ / ログイン | 標準的な一覧・詳細画面 |

## 「対戦」フロー（統一エントリ）

CPU戦・オンライン対戦を別モードとして選ばせず、常に以下の1本の流れにする。

1. 「対戦」をタップ → 常にまずオンラインのマッチング待機に入る（最大7秒）
2. 7秒以内に3人揃えば、そのままオンライン対局として対局画面へ
3. 7秒で揃わなければ、クライアントが`matchmaking.cancel`を呼び、**空席をCPUが自動的に埋めて**対局画面へ進む
4. **どちらの経路で始まった対局も記録され、`player_difficulty_stats`に反映される**（DBスキーマの変更は不要。`matches.mode`は`online_random`のまま、空席の`match_players.user_id`がnullになるだけ）

難易度を自分で選んで練習したい場合は、別導線の「オフライン練習」を使う（こちらは戦績・祝儀収支の対象外）。

### 難易度とレートの対応

「対戦」で選ぶのは**難易度**（簡単/中/難）のみ。レートは選ばない — 難易度に紐づいて自動的に決まる。

| 難易度 | レート（固定値） | CPU強さ（フォールバック時） |
|---|---|---|
| 簡単 | 0.5 | 初級 |
| 中 | 100 | 中級 |
| 難 | 200 | 上級 |

マッチングは「ルール設定＋難易度」が一致するプレイヤー同士でグルーピングする。フォールバックCPUの強さは選んだ難易度から直接決まるため、動的なスキル推定は不要。

## アニメーション仕様

| 場面 | 内容 |
|---|---|
| 牌移動 | ツモ・打牌・鳴きは150〜220msのイーズアウトで移動（瞬間移動させない） |
| ドラ表示演出 | 表示牌がめくれる瞬間に軽く持ち上げてから伏せて表を見せる（300ms）。北抜き・華抜き・アリス・チューリップのめくりも同じモーションを再利用 |
| リーチ演出 | 宣言牌を横向きに置く＋卓の外周に細い金色のラインが一瞬灯る。オープン立直は手牌が扇状に開く専用モーション |
| 和了演出 | 手牌が中央に寄り役・翻数・点数を積み上げ表示。祝儀チップ演出（春・アリス・チューリップ・青ドラ）は点数確定後に専用アニメーションとして分離 |
| アクセシビリティ | OSの「モーション削減」設定を尊重し、演出をフェード＋即時配置に切り替えるオプションを用意 |

## ルール設定画面のグルーピング

STEP5のトグル・数値項目（20以上）は以下の4カテゴリに分ける。

| カテゴリ | 項目 |
|---|---|
| ドラ | 赤/青ドラプリセット、白ポッチ有無、華牌有無、北ドラ有無、裏ドラ |
| 鳴き・和了 | 食いタン、後付け、一発、ダブロン |
| 点数 | 持ち点、返し点、ウマ、オカ、ツモ損、飛び終了 |
| 進行 | 延長戦、CPU強さ（オフライン練習のみ表示） |

友人戦のルーム作成時は「プリセットから選ぶ」を既定にし、カスタマイズは折りたたみで詳細を開く2段階構成にする。
