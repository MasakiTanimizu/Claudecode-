# レガシー: チューリップ祝儀ルール版（アーカイブ）

このディレクトリは、新しい三人麻雀アプリ（Flutter/Dart, `apps/mobile` + `server` + `packages/mahjong_engine`）の開発着手前にリポジトリに存在していた、別ルール（チューリップ祝儀ルール）のWeb版三人麻雀アプリ（React + Vite）をそのままアーカイブしたものです。

新プロジェクトとは無関係の別ルール・別実装のため、参照用としてのみ残しています。開発は行いません。

```bash
cd docs/legacy
npm install
npm run dev
```
